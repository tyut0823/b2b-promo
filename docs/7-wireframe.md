## 1. 개요

본 문서는 `3-PRD.md`의 기능 요구사항과 `4-user-scenario.md`의 화면별 시나리오를 근거로, `5-project-principle.md`에서 정의한 Page 컴포넌트 단위로 주요 화면의 레이아웃을 텍스트 기반 와이어프레임으로 정리한다.

모든 화면은 모바일(360px 기준 1컬럼 세로 배치)을 기본 레이아웃으로 하고, 데스크탑에서 달라지는 부분만 화면별로 간단히 언급한다. 문서에 근거 없는 검색창, 필터, 페이지네이션, 알림 배지 등은 포함하지 않는다.

## 2. 반응형 원칙

PRD 5절(모바일/데스크탑 대응 반응형 웹 UI)에 따라 아래 공통 기준을 모든 화면에 동일하게 적용한다. 화면별 "데스크탑 차이"는 이 원칙을 각 화면에 대입한 결과다.

- **Breakpoint**: 768px 미만은 모바일 레이아웃, 768px 이상은 데스크탑 레이아웃 하나만 사용한다(태블릿 전용 레이아웃 별도 정의 없음).
- **네비게이션**: 모바일은 상단에 텍스트 링크를 세로로 나열, 데스크탑은 한 줄 가로 배치로 전환한다.
- **목록형 화면**(샘플 목록, 내 신청 내역, 신청 현황, 샘플 관리 목록): 모바일은 카드 1열 세로 스택, 데스크탑은 표(테이블) 또는 그리드(2~3열)로 전환한다.
- **폼 화면**(회원가입, 샘플 등록/수정, 마이페이지): 모바일은 입력 필드 1열 세로 배치, 데스크탑은 관련 필드를 좌우 2단으로 배치할 수 있다(전체 폭은 고정 최대폭 내로 제한).
- **상세 화면**(샘플 상세): 모바일은 이미지 위·텍스트 아래 세로 배치, 데스크탑은 이미지·텍스트 좌우 2단 배치로 전환한다.
- 위 기준을 벗어나는 별도의 반응형 처리(예: 별도 모바일 전용 화면, 네이티브 앱 대응)는 도입하지 않는다.

```
| 소속 거래처명               |  새 비밀번호                      |
| [__________________]      |  [__________________]           |
|                            |                                 |
| [   내 정보 저장   ]       |  [   비밀번호 변경   ]           |
+------------------------------------------------------------+
```

**주요 요소**
- 내 정보(이름, 소속 거래처명) 조회/수정 영역과 저장 버튼
- 비밀번호 변경 영역(현재 비밀번호·새 비밀번호 입력, 변경 버튼 — 현재 비밀번호는 백엔드가 검증에 필요로 하여 실제 구현에 포함됨)
- 관리자/거래처 담당자 공통 화면(역할에 따른 항목 차이 없음)

## 11. 일일 신청 가능 개수 룰렛 (RouletteModal / RouletteResultModal, 거래처 담당자용, 부가 기능)

> 원 요구사항에는 없는 화면이며 사용자 요청으로 추가됨(`1-domain-definition.md` 6-1절 참고). 모바일/데스크탑 레이아웃 차이는 없고(작은 모달 하나), 반응형 원칙(2절) 적용 대상에서 제외한다.

**최초 로그인 시 뜨는 룰렛 모달 (RouletteModal)**
```
+--------------------------+
|   오늘의 신청 가능 개수    |
|                          |
|         ▼                |
|      /‾‾‾‾‾\             |
|     | 1 2 3 |  (회전판)   |
|      \_____/             |
|                          |
|       [ STOP ]           |
+--------------------------+
```
STOP을 누르면 회전판이 감속하며 1~3 중 하나에 멈추고, 아래로 전환된다:
```
+--------------------------+
|   오늘의 신청 가능 개수    |
|      (정지된 회전판)       |
| 오늘은 샘플을 최대 N개까지  |
| 신청할 수 있어요!          |
|       [  확인  ]         |
+--------------------------+
```

**네비게이션의 "오늘 신청 가능: N개" 클릭 시 뜨는 결과 재조회 모달 (RouletteResultModal)**
```
+--------------------------+
|     오늘의 룰렛 결과       |
|      (정지된 회전판)       |
| 오늘 뽑은 개수: N개         |
| (남은 개수: M개)           |
|       [  닫기  ]         |
+--------------------------+
```

**주요 요소**
- 회전판(1~3 세 구간으로 나뉜 원형), 상단 고정 포인터
- 계속 회전 → STOP 클릭 시 감속하며 결과 값에 정지 → 결과 문구 + 확인 버튼
- 그날 이미 뽑았으면 재로그인해도 이 모달은 다시 뜨지 않는다
- 네비게이션의 개수 표시를 클릭하면 같은 회전판을 오늘 뽑은 결과 위치에 정지된 채로 다시 보여준다(재추첨 아님)
