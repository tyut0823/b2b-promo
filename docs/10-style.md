## 1. 개요

이 문서는 사용자가 첨부한 식자재 B2B 발주 시스템("ONLYONE FOODNET") 화면 캡처 4장(로그인 화면, 일반주문 목록, 이벤트 모달, 메뉴 상세)에서 추출한 시각 스타일을 b2b-promo에 적용하기 위한 가이드다.

참고 화면은 실제 운영 중인 대형 ERP형 발주 시스템으로 탭·컬럼이 매우 많지만, b2b-promo는 `docs/7-wireframe.md`에 정의된 8개 화면(로그인/회원가입/샘플 목록·상세/내 신청내역/샘플 관리/신청 현황/마이페이지)만 다루는 교육용 MVP다. 따라서 이 문서는 참고 화면의 **기능 구성이 아니라 색상·타이포그래피·컴포넌트 형태 등 시각 언어만** 가져와 b2b-promo 화면에 맞게 단순화해서 정의한다.

## 2. 컬러 팔레트

### 2.1 브랜드/기본 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-primary` | `#1B5E42` | 헤더/로그인 패널 배경, 주요 버튼(로그인, 신청하기, 저장), 활성 탭 강조선 |
| `--color-primary-hover` | `#154A34` | 주요 버튼 hover/active |
| `--color-primary-light` | `#EAF3EE` | 강조 배경(총계 행, 선택된 카드 배경 등 옅은 녹색 톤) |
| `--color-white` | `#FFFFFF` | 기본 배경, 버튼 텍스트(녹색 배경 위) |

### 2.2 중립(텍스트/배경/테두리) 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-text` | `#222222` | 본문/제목 텍스트 |
| `--color-text-muted` | `#767676` | 보조 텍스트(안내문, 라벨, 날짜) |
| `--color-border` | `#E0E0E0` | 입력 필드/테이블/카드 테두리 |
| `--color-bg` | `#F7F8FA` | 페이지 배경(콘텐츠 영역) |
| `--color-bg-panel` | `#FFFFFF` | 카드/테이블/모달 배경 |

### 2.3 상태/배지 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-status-ok` | `#2E7D32` | 신청 가능(진행중/ONGOING) 상태 표시 |
| `--color-status-warn` | `#F5A623` | 마감 임박(신청 예정/SCHEDULED) 상태 표시 |
| `--color-status-danger` | `#E53935` | 신청 마감(종료/ENDED), 오류/취소 상태 표시 |
| `--color-badge-dark` | `#111111` | 강조 배지 배경(예: "AI Pick"류 추천 배지) — b2b-promo에는 없지만 팔레트로만 보유 |
| `--color-badge-outline` | `#D32F2F` | 강조 아웃라인 배지 텍스트/테두리(예: 인증 배지) |

> 참고 화면의 상태 점(●) 색상 3단계(초록/노랑/빨강)를 b2b-promo의 샘플 상태(`ONGOING`/`SCHEDULED`/`ENDED`) 배지 색상에 그대로 대응시킨다.

## 3. 타이포그래피

- 폰트: `"Noto Sans KR", "Malgun Gothic", -apple-system, sans-serif` (시스템 폰트 우선, 별도 웹폰트 로딩 없음 — 3일 MVP 규모에 맞춤)
- 기준 크기: `16px` (모바일 우선, 데스크탑도 동일 기준 유지)

| 용도 | 크기 | 굵기 | 색상 |
|---|---|---|---|
| 페이지 제목(H1) | 24px | 700 | `--color-text` |
| 섹션 제목(H2, 카드 헤더) | 18px | 700 | `--color-text` |
| 본문 | 15px | 400 | `--color-text` |
| 보조 텍스트(라벨/날짜/안내문) | 13px | 400 | `--color-text-muted` |
| 가격/수치 강조 | 16px | 700 | `--color-text` |
| 버튼 텍스트 | 15px | 700 | 배경에 따라 흰색 또는 `--color-primary` |

## 4. 여백/레이아웃

- 기본 여백 단위: 4px 배수 (`4px, 8px, 12px, 16px, 24px, 32px`)
- 카드/패널 모서리: `border-radius: 8px`
- 버튼 모서리: `border-radius: 6px`
- 입력 필드 모서리: `border-radius: 4px`
- 콘텐츠 최대 폭(데스크탑): `1200px`, 좌우 중앙 정렬
- 모바일 콘텐츠 좌우 패딩: `16px`

## 5. 컴포넌트 스타일

### 5.1 버튼

| 종류 | 배경 | 텍스트 | 사용처 |
|---|---|---|---|
| Primary | `--color-primary` | 흰색 | 로그인, 신청하기, 등록/수정 저장, 확인 |
| Secondary(아웃라인) | 흰색, `--color-border` 테두리 | `--color-text` | 취소, 목록으로 |
| 위험(취소/삭제성) | 흰색, `--color-status-danger` 테두리 | `--color-status-danger` | 신청 취소 |

- 버튼 높이: 모바일/데스크탑 공통 `44px` (터치 타깃 확보)
- 버튼 폭: 폼 하단 액션 버튼은 컨테이너 전체 폭(모바일), 데스크탑에서는 콘텐츠 폭에 맞춰 최소 `120px`

### 5.2 입력 필드

- 참고 화면의 로그인 인풋(아이콘 + placeholder, 녹색 배경 위 흰 테두리)은 b2b-promo 로그인 화면에도 동일하게 적용: 흰색 텍스트/테두리, 배경은 `--color-primary`
- 그 외 일반 폼(회원가입, 샘플 등록/수정, 마이페이지)은 흰 배경 + `--color-border` 테두리 + 포커스 시 `--color-primary` 테두리로 강조
- 높이: `44px`, 좌우 패딩 `12px`

### 5.3 상태 배지 (샘플 상태)

원형 점 + 라벨 조합(참고 화면의 마감 상태 표시 방식 재사용):

| 상태 | 표시 | 색상 |
|---|---|---|
| `ONGOING` (신청 가능) | ● 신청 가능 | `--color-status-ok` |
| `SCHEDULED` (신청 예정) | ● 신청 예정 | `--color-status-warn` |
| `ENDED` (신청 종료) | ● 신청 종료 | `--color-status-danger` |
| `APPLIED` (신청 내역 상태) | ● 신청 | `--color-status-ok` |
| `CANCELLED` (신청 내역 상태) | ● 취소 | `--color-text-muted` |

### 5.4 카드/목록 (샘플 목록, 신청 내역)

모바일 1열 카드 목록은 참고 화면의 상품 테이블 대신, 정보 밀도를 낮춘 카드 형태를 사용한다(교육용 MVP, 컬럼이 20개가 넘는 원본 테이블 형태는 채택하지 않음):

- 카드: 흰 배경, `--color-border` 1px 테두리, `border-radius: 8px`, 내부 패딩 `16px`
- 카드 안 구성: 썸네일(좌) + 제목/기간/상태 배지(우) — `7-wireframe.md` 5·7절 구조 유지
- 데스크탑에서는 카드 그리드(2~3열) 또는 표(관리자 화면)로 전환(`7-wireframe.md` 반응형 원칙 그대로 따름)

### 5.5 상단 네비게이션

참고 화면의 상단 고정 바(로고 + 검색 + 우측 아이콘) 스타일을 단순화해서 채택:

- 높이: `56px`, 배경 흰색, 하단 `--color-border` 1px
- 로고: 좌측, `--color-primary` 텍스트/워드마크
- 활성 메뉴: 텍스트 `--color-primary` + 하단 2px 밑줄(참고 화면의 "주문" 탭 활성 표시 방식)
- 모바일: 로고만 남기고 메뉴는 하단 탭 또는 슬라이드 메뉴로 축약(`5-project-principle.md`의 AdminLayout/BuyerLayout 반응형 헤더 원칙과 연결)

### 5.6 모달

참고 화면의 이벤트 모달 스타일을 확인/안내용 모달에 재사용:

- 배경 오버레이: `rgba(0,0,0,0.5)`
- 모달 박스: 흰 배경, `border-radius: 8px`, 최대 폭 `480px`(모바일은 화면 폭의 `90%`)
- 우측 상단 닫기(X) 아이콘, 하단 Primary 버튼 1개 배치
- 용도(b2b-promo 범위): 신청/취소 확인 다이얼로그, 안내 메시지("이미 신청한 샘플입니다." 등)

## 6. 반응형 원칙 연결

이 문서의 컬러/타이포그래피/컴포넌트 스펙은 `docs/7-wireframe.md` 2절(반응형 원칙, breakpoint 768px)과 함께 사용한다. 레이아웃 구조(모바일 1열 → 데스크탑 그리드/표 전환)는 와이어프레임 문서를 따르고, 이 문서는 그 레이아웃 안에 채워질 색상·타이포그래피·컴포넌트 형태만 정의한다.
